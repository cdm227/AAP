# Ansible Automation Platform & GitHub Actions

Welcome! This project demonstrates how to integrate Ansible playbooks with GitHub Actions for seamless automation, deployment, and CI/CD.

[Repository on GitHub](https://github.com/cdm227/AAP)

---

## 🚀 Quickstart

1. **Clone the repo**

   ```bash
   git clone https://github.com/cdm227/AAP.git
   cd AAP
   ```

2. **Configure your inventory**

   Edit `inventory/hosts.ini` to match your target hosts.

3. **Set up secrets**

   Add SSH keys and any required secrets via your repository settings for workflow access.

4. **Trigger workflows**

   Use GitHub Actions to run/play the sample playbooks or deploy to your own infrastructure.
